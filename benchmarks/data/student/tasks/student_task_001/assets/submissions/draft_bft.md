# Draft: Understanding Byzantine Fault Tolerance
By Devon

In distributed systems, nodes can fail. Some fail by crashing, while others send conflicting messages.
PBFT is an algorithm that provides consensus even when malicious nodes exist.
Nodes exchange PRE-PREPARE, PREPARE, and COMMIT messages.
Overall, Byzantine fault tolerance is important for blockchains and critical systems.
